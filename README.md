# Estudando Python - Fundamentos e Lógica de Programação 🐍

Este repositório reúne os meus estudos diários em Python, focando na consolidação da lógica de programação e resolução de problemas práticos.

## 📌 Conteúdos e Exercícios

- **Variáveis e Operadores:** Exercícios práticos de fixação e manipulação de tipos de dados.
- **Estruturas Condicionais:** Algoritmos de tomada de decisão (ex: Calculadora de IMC com faixas de classificação).
- **Projetos de Consolidação:** Pequenos scripts executáveis no terminal.

## 🛠️ Tecnologias e Ferramentas Utilizadas
- **Linguagem:** Python 3
- **IDE:** Visual Studio Code (VS Code)
- **Controle de Versão:** Git / GitHub
